**Παρατηρητήριο Δεδομένων Αιγαίου**: πλατφόρμα παρακολούθησης δεδομένων σε πραγματικό χρόνο
για μικροκλίμα, καιρό και ποιότητα αέρα, σε σταθμούς σε όλο το Αιγαίο.

---


## Επισκόπηση

Το **AegeanSense** είναι το frontend μιας πλατφόρμας παρακολούθησης
κλιματικών σταθμών, μέρος διπλωματικής εργασίας στο Πανεπιστήμιο Αιγαίου. Συλλέγει
και οπτικοποιεί δεδομένα σε πραγματικό χρόνο (θερμοκρασία, υγρασία, άνεμος,
βροχόπτωση, ποιότητα αέρα) από σταθμούς σε διάφορες τοποθεσίες, με στόχο την
υποστήριξη έρευνας και εφαρμογών γεωργίας ακριβείας.



Το backend (FastAPI) εκτίθεται ξεχωριστά και αποτελεί την πηγή αλήθειας για τα
δεδομένα των σταθμών· αυτό το repository καλύπτει αποκλειστικά το frontend.

## Λειτουργίες


|                                       |                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------- |
| **Διαδραστικός χάρτης**           | Τοποθεσίες σταθμών με κατάσταση λειτουργίας σε πραγματικό χρόνο (Leaflet) |
| **Χρονοσειρές & γραφήματα**        | Ιστορικά και live δεδομένα ανά μεταβλητή, με Highcharts                   |
| **Παρακολούθηση μικροκλίματος**   | Θερμοκρασία, υγρασία, άνεμος, έδαφος ανά σταθμό                           |
| **Πίνακας ελέγχου (Dashboard)**    | Λεπτομερής προβολή ανά σταθμό με πλοήγηση ημερομηνιών                     |
| **Διαχειριστικό πάνελ**            | Πανελ διαχείρισης προφιλ, σταθμων και συγχρονισμος δεδομενων                     |


## Τεχνολογίες

- **[Next.js 15](https://nextjs.org/)** & **React 19**
- **TypeScript**, **Tailwind CSS 4**
- **[Highcharts](https://www.highcharts.com/)** για γραφήματα χρονοσειρών
- **[Leaflet](https://leafletjs.com/)** / react-leaflet για τον χάρτη σταθμών
- **Radix UI** primitives + **shadcn/ui** στυλ components
- FastAPI backend (ξεχωριστό repository) ως πηγή δεδομένων



- Node.js 20+
- Το backend API να τρέχει (προεπιλογή: `http://localhost:8000`)

```bash
git clone <this-repo-url>
cd aegeansense-web
npm install
```

Δημιουργήστε ένα αρχείο `.env.local`:

```bash
NEXT_PUBLIC_API_URL=http://localhost:8000
```
```bash
npm run dev
```
